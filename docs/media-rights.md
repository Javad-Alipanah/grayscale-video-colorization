# Media rights

This repository distributes original code, documentation and synthetic examples.
It does not distribute Feynman recordings, audio, extracted stills, contact sheets
or generated references derived from them.

On 7 October 2026, the [official Caltech page](https://www.feynmanlectures.caltech.edu/messenger.html)
described a renewed BBC license for website viewing. We found no public grant for
visitors to redistribute or publish colorized full lectures. Free viewing,
attribution and educational/noncommercial intent do not establish that permission.

For a public release, seek clearance for the entire programme, the particular
restored source, colorization, worldwide YouTube/platform rights and any repository
stills/forks. Ask [the website](https://www.feynmanlectures.caltech.edu/info/contact.html)
about its restored master and [BBC Studios](https://www.bbcstudios.com/contact/faqs/)
for the appropriate programme-rights route. Its FAQ routes clips to BBC Motion
Gallery/Getty; a clip license should not be presumed to cover the whole lecture.

YouTube's [terms](https://www.youtube.com/t/terms) and
[copyright guidance](https://support.google.com/youtube/answer/2797466?hl=en)
also apply. Rights-holder permission and applicable legal exceptions are distinct
possible bases; this project has not established an exception for its full-film
release. No media publication or endorsement is implied by the code repository.
